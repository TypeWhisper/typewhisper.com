# Add-on distribution audit — 2026-09-28

The source label of every add-on was checked against the app sources, the release packages, and the published plug-in catalogs. The audit covers 52 add-ons with 49 macOS and 39 Windows implementations. No add-on lists iOS as a platform.

## Result

The label "Bundled" ("Mitgeliefert") was wrong for 44 of the 45 add-ons that carried it. Only Apple Speech is part of an app. Every other add-on is downloaded from the plug-in catalog of its platform, on macOS and on Windows alike.

| Source | Label (en / de) | Before | After |
| --- | --- | --- | --- |
| `bundled`, now `built-in` | Built in / Eingebaut | 45 | 1 |
| `official` | Marketplace / Marketplace | 6 | 50 |
| `community` | Community / Community | 1 | 1 |

One value per add-on is true on all of its platforms, so `source` stays a field of the add-on and the platform editions carry no value of their own.

## Evidence per platform

### macOS

- The Xcode project has one copy phase for plug-ins, "Embed Built-In Plugins" (destination 13, the `PlugIns` folder of the app). It holds a single file, `SpeechAnalyzerPlugin.bundle`: [`project.pbxproj` lines 685 to 694](https://github.com/TypeWhisper/typewhisper-mac/blob/3b8e8953/TypeWhisper.xcodeproj/project.pbxproj#L685-L694) on `main` (1.7 line, `3b8e8953`). The 1.6 release branch has the same phase with the same single file: [lines 592 to 601](https://github.com/TypeWhisper/typewhisper-mac/blob/eaa7832a/TypeWhisper.xcodeproj/project.pbxproj#L592-L601) (`eaa7832a`).
- The app loads plug-ins from the user's plug-in folder and from `Bundle.main.builtInPlugInsURL`: [`PluginManager.swift` lines 611 to 617](https://github.com/TypeWhisper/typewhisper-mac/blob/3b8e8953/TypeWhisper/Services/PluginManager.swift#L611-L617).
- The catalog the app reads is `plugins-community-v1.json`: [`PluginRegistryService.swift` line 474](https://github.com/TypeWhisper/typewhisper-mac/blob/3b8e8953/TypeWhisper/Services/PluginRegistryService.swift#L474). An entry without a `source` is an official one: [line 287](https://github.com/TypeWhisper/typewhisper-mac/blob/3b8e8953/TypeWhisper/Services/PluginRegistryService.swift#L287). The catalog on `gh-pages` (`233327e2`) has 50 entries; MemPalace is the only one marked `"source": "community"`.
- Apple Speech is also listed in the catalog. That entry delivers updates of the embedded plug-in.

### Windows

- The stable release is 1.0.9 (tag `v1.0.9`, `41e62b24`). Its packages contain no plug-in: `TypeWhisper-win-x64-Portable.zip` (SHA-256 `285ff32bad4a4643c64d97d0d6a1b7d63b0d7b57877cbf1c0704ae8f7105939d`) and `TypeWhisper-1.0.9-win-x64-full.nupkg` (SHA-256 `3d025ba68ca24a79b773f3d45f4af2c4bc52394394e3be8805a900d1e3236944`) from the [GitHub release](https://github.com/TypeWhisper/typewhisper-win/releases/tag/v1.0.9) were downloaded and listed; neither has a `Plugins` folder. The ARM64 packages have the same size class (20 MB) and were not opened.
- The sources agree: the release workflow publishes only the app project ([`release.yml` lines 86 and 87](https://github.com/TypeWhisper/typewhisper-win/blob/41e62b24/.github/workflows/release.yml#L86-L87)), the solution lists no plug-in project ([`TypeWhisper.slnx`](https://github.com/TypeWhisper/typewhisper-win/blob/41e62b24/TypeWhisper.slnx)), and the app project references none ([`TypeWhisper.Windows.csproj`](https://github.com/TypeWhisper/typewhisper-win/blob/41e62b24/src/TypeWhisper.Windows/TypeWhisper.Windows.csproj)).
- The app would load plug-ins from a `Plugins` folder beside the executable ([`PluginRegistryService.cs` line 98](https://github.com/TypeWhisper/typewhisper-win/blob/41e62b24/src/TypeWhisper.Windows/Services/Plugins/PluginRegistryService.cs#L98)), but the release packages do not fill it. The README of the tag and older release notes still speak of "bundled plugins"; the packages do not back that.
- The catalog of the stable line is `plugins.json` ([`PluginRegistryService.cs` line 21](https://github.com/TypeWhisper/typewhisper-win/blob/41e62b24/src/TypeWhisper.Windows/Services/Plugins/PluginRegistryService.cs#L21)). On `gh-pages` (`c689d569`) it has 39 entries, one for each Windows add-on of the website. First-run installation of marketplace plug-ins is switched off since 1.0.1.
- The 1.1 line downloads plug-ins on demand from `plugins-v2.json` ([`docs/PLUGIN-PACKAGES-1.1.md` line 4](https://github.com/TypeWhisper/typewhisper-win/blob/30dabdc7/docs/PLUGIN-PACKAGES-1.1.md)); its packages have "no bundled plugin directory" ([`docs/releases/1.1-daily-validation.md` line 17](https://github.com/TypeWhisper/typewhisper-win/blob/30dabdc7/docs/releases/1.1-daily-validation.md)). The label "Marketplace" stays true after that release.

### iOS

- The iOS app (`d73af45` on `main`) has no plug-in catalog and no marketplace; a search of the repository for "marketplace" finds nothing, and "plugin" appears only in a test of the keyboard extension. Engines and cloud providers are part of the app.
- No add-on of the website lists iOS, so no add-on needs a source for it. The add-on index points to the iOS guide instead.

### Separate plug-in repository

- `typewhisper-plugins` is retired (`ea34772`, "Retire standalone plugin repository"). Plug-ins live in the platform repositories; `src/data/community-plugins.json` is empty.
