id: com.typewhisper.xai
minAppVersion: "1.1.0"
requirements:
  - TypeWhisper 1.1.0 or newer
  - Windows 10 or newer
  - An xAI API key
highlights:
  - Grok Voice Transcribe 2.0 or 1.0 for recorded audio and for live text while you dictate
  - Up to 100 dictionary terms sent to xAI as key terms
  - Grok text models for workflow prompts, with Grok 4.3 as the default and the models of your account after a refresh
  - Text-to-speech with the voices Eve, Ara, Leo, Rex and Sal, voices loaded from xAI, or a custom voice ID
  - Optional low-latency speech output and spoken forms for numbers, abbreviations and symbols
configuration:
  - Enter your xAI API key, select Save settings, then Check connection
  - Choose Grok Voice Transcribe 2.0 or 1.0 under Transcription model, and turn on Live transcription under Appearance if you want live text
  - Select Refresh text models and choose the Text model for text processing
  - Select Refresh voices, choose a Voice or enter a Custom voice ID (optional), set Low-latency speech and Normalize spoken text, then select Save settings
