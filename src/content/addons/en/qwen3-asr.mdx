## About

Qwen3 ASR is a local speech recognition engine powered by the Qwen3 audio model, running via Apple's MLX framework. All processing happens entirely on your Mac - no cloud, no API key required. Qwen3 ASR delivers strong multilingual accuracy with efficient on-device inference on Apple Silicon.

## Features

- Fully on-device transcription via MLX
- Multilingual speech recognition
- Optimized for Apple Silicon
- No API key or cloud account needed
- Bundled with TypeWhisper - install from the plugin manager

## Configuration

No API key required. Qwen3 ASR runs entirely on-device.

## Setup

1. Open TypeWhisper Settings > Plugins
2. Find the Qwen3 ASR plugin and enable it
3. The model will be downloaded on first use
4. Select Qwen3 ASR as your transcription engine in Settings or in a profile
