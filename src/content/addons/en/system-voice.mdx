## Setup

1. Open **Settings > Integrations** and enable **System Voice**.
2. Choose an installed voice or keep **System Default**.
3. Set a speaking rate in words per minute, or keep the system default.
4. Select System Voice as the text-to-speech provider for readback or spoken feedback.

Speech is generated locally using macOS voices. No provider API key is required. Available voices and languages depend on the voices installed in macOS; downloading additional system voices can require internet access.

This is a text-to-speech provider. Select a separate transcription engine for speech recognition.
