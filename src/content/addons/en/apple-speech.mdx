## About

Apple Speech uses Apple's native Speech framework for fully on-device speech recognition. It provides real-time streaming with interim results and automatically manages language model downloads. Requires macOS 26.0 or later.

## Features

- Apple's native Speech framework
- Fully on-device processing
- Real-time streaming with interim results
- Automatic language model download
- No API key or cloud account needed

## Transcription Models

Models are managed automatically by the system - one model per language, downloaded on demand.

When TypeWhisper starts, it restores the last selected language only if its model is already installed; it does not download anything at launch. If **Auto-unload model** is set to **Immediate**, the selected language shows **Loads on demand** instead of a checkmark, because the model is loaded for each transcription and unloaded right after.

## Configuration

No API key required. Apple Speech runs entirely on-device.

## Setup

1. Make sure you are running macOS 26.0 or later.
2. Apple Speech is built into TypeWhisper. Select **Apple Speech** in the Settings sidebar. If its page says that the plugin is disabled, click **Enable**.
3. Language models are downloaded automatically when needed.
4. Select Apple Speech as your transcription engine in Settings or in a profile.
