## About this edition

Groq provides cloud transcription with Whisper models and LLM text processing through one API key. Select Groq for speech, workflow prompts, or both. Available models and usage limits depend on your Groq account.

## Features

- Cloud transcription with Whisper models
- Multiple Whisper model variants
- LLM processing with GPT-OSS and Qwen models
- Reasoning effort per model on Mac, for example Low for GPT-OSS 120B
- Account-specific usage limits
- OpenAI-compatible API

## Transcription Models

| Model | ID |
| --- | --- |
| Whisper Large V3 | `whisper-large-v3` |
| Whisper Large V3 Turbo | `whisper-large-v3-turbo` |

## LLM Models

| Model | ID | Reasoning effort on Mac |
| --- | --- | --- |
| GPT-OSS 20B | `openai/gpt-oss-20b` | Low, Medium (Groq default), High |
| GPT-OSS 120B | `openai/gpt-oss-120b` | Low, Medium (Groq default), High |
| Qwen 3.8 27B | `qwen/qwen3.8-27b` | Off (Groq default), Low, Medium, High |
| Muse Spark | `meta-models/muse-spark-open` | Low, Medium, High, Extra High (Groq default) |

Refresh the model catalog in TypeWhisper to see the models available to your account. Muse Spark appears only after you accept its terms in the Groq console.

On Mac, the Reasoning Effort setting picks how long a model reasons before it answers. Lower levels answer faster and use fewer tokens, which suits cleaning up dictations. Until you pick a level, Groq uses its own default. Workflows can pick their own level. Check [Groq’s deprecation notices](https://console.groq.com/docs/deprecations) when an older saved model stops working.

## Configuration

- **API Key** - Sign up at console.groq.com and generate a free API key.

## Setup

1. In TypeWhisper, open **Settings > Discover plugins** and install **Groq**. The add-on then appears in the Settings sidebar, and its page opens.
2. Enter your Groq API key.
3. Select Groq as your transcription engine or LLM provider.
4. On Mac, choose a Reasoning Effort if the LLM model offers one.
