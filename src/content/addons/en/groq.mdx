## About this edition

Groq provides cloud transcription with Whisper models and LLM text processing through one API key. Select Groq for speech, workflow prompts, or both. Available models and usage limits depend on your Groq account.

## Features

- Cloud transcription with Whisper models
- Multiple Whisper model variants
- LLM processing with GPT-OSS models
- Account-specific usage limits
- OpenAI-compatible API

## Transcription Models

| Model | ID |
| --- | --- |
| Whisper Large V3 | `whisper-large-v3` |
| Whisper Large V3 Turbo | `whisper-large-v3-turbo` |

## LLM Models

| Model | ID |
| --- | --- |
| GPT-OSS 20B | `openai/gpt-oss-20b` |
| GPT-OSS 120B | `openai/gpt-oss-120b` |

Refresh the model catalog in TypeWhisper to see the models available to your account. Check [Groq’s deprecation notices](https://console.groq.com/docs/deprecations) when an older saved model stops working.

## Configuration

- **API Key** - Sign up at console.groq.com and generate a free API key.

## Setup

1. Open TypeWhisper Settings > Integrations
2. Find the Groq plugin and click Configure
3. Enter your Groq API key
4. Select Groq as your transcription engine or LLM provider
