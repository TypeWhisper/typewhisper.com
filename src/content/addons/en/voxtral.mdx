## About

Voxtral brings Mistral's speech recognition model to your Mac via Apple's MLX framework. All processing runs locally with no cloud connection required. Voxtral supports 15 languages and offers real-time streaming transcription.

For Mistral's cloud transcription with Voxtral Transcribe 3 and Voxtral Realtime, on Mac and Windows, use the [Mistral AI](/en/addons/mistral/) add-on.

## Features

- Mistral's Voxtral model running locally via MLX
- 15 languages supported
- Real-time streaming transcription
- No API key or cloud account needed

## Transcription Models

| Model | ID | Size |
| --- | --- | --- |
| Mini 4B (4-bit) | `voxtral-mini-4b-2602-4bit` | ~2.5 GB |
| Mini 4B (fp16) | `voxtral-mini-4b-2602-fp16` | ~8 GB |

## Import your own model

Since version 1.0.15, **Import Model…** next to **Model** adds a Voxtral Realtime model that is not in the list. Under **Source**, choose **Hugging Face** and enter the Hugging Face model URL, or **Local Folder** and choose a folder with `config.json`, `tekken.json` and `.safetensors` weights. TypeWhisper keeps its own copy; your original files are not changed. A Hugging Face token is only needed for private or gated models; it is used for this import and is not saved.

The model is checked and loaded before the import completes, and a model of another architecture is rejected. Imported models appear in the model list as **Imported model** with a **Load** button.

## Configuration

No API key required. Voxtral runs entirely on-device.

## Setup

1. In TypeWhisper, open **Settings > Discover plugins** and install **Voxtral**. The add-on then appears in the Settings sidebar, and its page opens.
2. The model will be downloaded on first use. If **Auto-unload model** is set to **Immediate**, a downloaded model shows **Loads on demand**: it is loaded for each transcription and unloaded right after.
3. Select Voxtral as your transcription engine in Settings or in a profile.
