## About

OpenAI / ChatGPT gives TypeWhisper high-quality speech-to-text via Whisper models and flexible prompt processing through OpenAI and ChatGPT/Codex models. The plugin supports both classic Whisper and the newer GPT-4o Transcribe model for improved accuracy. On macOS, you can either connect a regular OpenAI API key or use your existing ChatGPT Plus/Pro or Codex login for prompt processing.

## Features

- High-accuracy Whisper transcription
- GPT-4o Transcribe for enhanced accuracy
- GPT and ChatGPT/Codex models for LLM tasks
- o4-mini for fast, cost-effective processing
- Translation support via Whisper
- Sign in through your browser on macOS
- Import an existing Codex login on macOS

## Configuration

- **API Key** - Create an API key at platform.openai.com. Required for transcription and available for prompt processing.
- **ChatGPT Login** - On macOS, use your existing ChatGPT Plus/Pro subscription or Codex login for prompt processing without adding an OpenAI API key for prompts.

## Setup

1. Open TypeWhisper Settings > Plugins
2. Find the OpenAI / ChatGPT plugin and click Configure
3. Choose your connection method:
4. For API Key, enter your OpenAI API key
5. For ChatGPT Login on macOS, either click Sign In In Browser or Import Codex Login
6. If you want transcription, add an OpenAI API key even when using ChatGPT Login for prompts
7. Select OpenAI / ChatGPT as your transcription engine or LLM provider

## Notes

- ChatGPT Login is currently documented for macOS only.
- ChatGPT Login exposes only the supported ChatGPT/Codex models.
- Browser login and Codex import are intended for prompt processing, not as a replacement for the transcription API key.
