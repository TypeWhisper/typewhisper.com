## About

Granite brings IBM's Granite speech-to-text models to TypeWhisper, running entirely on-device using Apple's MLX framework. Like WhisperKit, all processing happens locally on your Mac's Apple Silicon chip - no cloud services or API keys needed.

## Features

- Fully local on-device transcription
- Powered by IBM Granite speech models
- Runs on Apple Silicon via MLX
- No API keys or cloud accounts required
- Privacy-friendly - audio never leaves your Mac

## Configuration

- **Model** - Select which Granite model variant to use.

## Setup

1. Open TypeWhisper Settings > Plugins
2. Find the Granite plugin and click Configure
3. Select your preferred model variant
4. Select Granite as your transcription engine in Settings or in a profile
5. The model will be downloaded automatically on first use
