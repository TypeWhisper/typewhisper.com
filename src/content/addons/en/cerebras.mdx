## About this edition

Cerebras provides cloud LLMs for TypeWhisper workflows. The macOS edition uses an OpenAI-compatible API and can refresh the model catalog. Model access, speed, and usage limits depend on the selected model and your account.

## Features

- Cloud LLMs for text workflows
- Dynamic model list with refresh from the Cerebras API
- Reasoning effort per model on Mac, for example Low for GPT-OSS 120B
- OpenAI-compatible API
- API keys stored securely in the macOS Keychain

## LLM Models

| Model | ID | Reasoning effort on Mac |
| --- | --- | --- |
| GPT-OSS 120B | `gpt-oss-120b` | Low, Medium (Cerebras default), High |
| Qwen 3.8 27B | `qwen-3.8-27b` | Off, Low, Medium, High (Cerebras default) |
| Kimi K3 | `kimi-k3` | Low, High, Max (Cerebras default) |
| Kimi K3.1 Pro | `kimi-k3.1-pro` | Low, Medium, High, Max (Cerebras default) |
| ZAI GLM 5.3 Flash | `zai-glm-5.3-flash` | Low, High, Max (Cerebras default) |
| Gemma 4 31B | `gemma-4-31b` | Off (Cerebras default), High |

GPT-OSS 120B is the default model. Use the Refresh button to load the models available to your Cerebras account.

On Mac, the Reasoning Effort setting picks how long a model reasons before it answers. Lower levels answer faster and use fewer tokens, which suits cleaning up dictations. Until you pick a level, Cerebras uses its own default. Workflows can pick their own level. Saved selections of Llama 3.1 8B, Qwen 3 235B Instruct and ZAI GLM 4.7, which Cerebras deprecated, switch to GPT-OSS 120B.

## Configuration

- **API Key** - Sign up at cloud.cerebras.ai and generate an API key. Your key is stored securely in the macOS Keychain.

## Setup

1. In TypeWhisper, open **Settings > Discover plugins** and install **Cerebras**. The add-on then appears in the Settings sidebar, and its page opens.
2. Enter your Cerebras API key.
3. Select an LLM model and choose Cerebras as your LLM provider.
4. On Mac, choose a Reasoning Effort if the model offers one.
