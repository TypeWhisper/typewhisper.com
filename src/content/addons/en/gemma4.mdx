## About

Gemma 4 brings Google's open-weight Gemma model family to TypeWhisper as a fully local LLM provider. Everything runs on your Mac with Apple's MLX framework, so you can use custom prompts, text transformations, summaries, and other AI workflows without sending data to the cloud.

## Features

- Fully local on-device LLM processing
- Powered by Google Gemma 4 models
- Runs on Apple Silicon via MLX
- No API keys or cloud accounts required
- Multiple model sizes for different RAM budgets

## Available Models

| Model | Download Size | Recommended RAM |
| --- | --- | --- |
| Gemma 4 E2B (4-bit) | ~3.6 GB | 8 GB+ |
| Gemma 4 E4B (4-bit) | ~5.2 GB | 16 GB+ |
| Gemma 4 E4B (8-bit) | ~8 GB | 16 GB+ |
| Gemma 4 26B-A4B (4-bit, MoE) | ~15.6 GB | 32 GB+ |

## Configuration

- **Model** - Choose which Gemma 4 model variant to download and load.

## Setup

1. Open TypeWhisper Settings > Plugins
2. Find the Gemma 4 plugin and click Configure
3. Download and load your preferred Gemma 4 model
4. Select Gemma 4 as the LLM provider in a custom prompt
5. Start using local AI workflows without an API key
