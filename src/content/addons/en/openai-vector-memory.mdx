## About this edition

The macOS edition stores and searches memories through **OpenAI Vector Stores**. It creates the vector store automatically after you save an API key; you do not enter a Vector Store ID manually.

## Setup

1. In TypeWhisper, open **Settings > Discover plugins** and install **OpenAI Vector Memory**. The add-on then appears in the Settings sidebar, and its page opens.
2. Save your OpenAI API key.
3. Wait for the connection status and automatically created store ID.
4. Enable this provider for workflow memories.
5. Review stored memories in the configuration. You can search, edit, and delete them.

Memory text and search queries are sent to OpenAI.
