## About

File Memory provides a fully local and offline memory system for TypeWhisper. Transcriptions and context are stored as JSON files on disk, and retrieval uses simple text-based search. No cloud services or API keys are required - everything stays on your Mac.

## Features

- Fully offline - no network access needed
- JSON file storage in a local directory
- Text-based search for memory retrieval
- No API keys or cloud accounts required
- Works without any external dependencies

## Configuration

- **Storage directory** - The folder where memory files are saved. Defaults to a directory inside TypeWhisper's application support folder.

## Setup

1. Open TypeWhisper Settings > Plugins
2. Find the File Memory plugin and click Configure
3. Optionally change the storage directory
4. The plugin will automatically store and retrieve memories as you use TypeWhisper
