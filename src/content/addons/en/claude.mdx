## About

Claude adds Anthropic's LLM capabilities to TypeWhisper for custom prompts and text workflows. Unlike OpenAI-compatible providers, this plugin talks directly to Anthropic's native API and uses the Messages API to process your prompt output.

## Features

- API key authentication via Anthropic
- API keys stored securely in the macOS Keychain
- Model picker in plugin settings
- Usable as the LLM provider for prompt-based workflows

## LLM Models

| Model | ID |
| --- | --- |
| Claude Sonnet 4.6 | `claude-sonnet-4-6` |
| Claude Opus 4.6 | `claude-opus-4-6` |
| Claude Haiku 4.5 | `claude-haiku-4-5` |

## Configuration

- **API Key** - Create an API key in the Anthropic Console on the Claude platform.

## Setup

1. In TypeWhisper, open **Settings > Discover plugins** and install **Claude**. The add-on then appears in the Settings sidebar, and its page opens.
2. Enter your Claude API key.
3. Select a Claude model.
4. Choose Claude as your LLM provider in a custom prompt.
