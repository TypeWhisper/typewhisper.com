## About this edition

On macOS, Cohere uses the **Cohere Transcribe** cloud API. On Windows, the same add-on family provides **Cohere Command** for text workflows. The following steps apply to macOS.

## Model and language

The transcription model is `cohere-transcribe-03-2026`. [Cohere documents](https://docs.cohere.com/docs/transcribe) support for Arabic, Chinese, Dutch, English, French, German, Greek, Italian, Japanese, Korean, Polish, Portuguese, Spanish, and Vietnamese.

The current macOS plugin advertises a different language list: it includes Bengali, Hindi, Russian, Swahili, and Turkish, and omits Dutch, Greek, Italian, Polish, and Vietnamese. Choose a language supported by both the model and the plugin; a language appearing in the app does not establish model support.

Select the spoken language explicitly. Without a language selection, the macOS edition sends English; it does not perform automatic language detection. Dictionary terms are not passed as inference hints. Local dictionary corrections can still run after transcription.

## Setup

1. Open **Settings > Integrations > Cohere**.
2. Save and validate your Cohere API key. The key is stored in macOS Keychain.
3. Select Cohere as the transcription provider and set the spoken language.
4. Check a short recording in that language.

Audio is sent to Cohere. For local recognition, use the separate **Cohere Transcribe (Local)** add-on.
