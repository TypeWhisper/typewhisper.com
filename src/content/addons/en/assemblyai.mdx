## About this edition

The macOS edition provides **Universal-3.5 Pro** and **Universal-2**. It uses live WebSocket transcription and falls back to REST processing when the connection fails. Enabling speaker diarization selects the structured REST path and disables live preview.

## Models

| Model | ID | Languages |
| --- | --- | --- |
| Universal-3.5 Pro | `universal-3-5-pro` | 18 |
| Universal-2 | `universal-2` | 37 |

Saved macOS selections of `universal-3-pro` migrate to Universal-3.5 Pro. The model and language determine the streaming endpoint. Dictionary terms are sent as model-specific recognition hints.

## Setup

1. Open **Settings > Integrations > AssemblyAI**.
2. Save and validate your AssemblyAI API key.
3. Choose a model and a supported language, or automatic detection.
4. Enable speaker diarization only when you need it.
5. Select AssemblyAI as the workflow's transcription provider.

Audio is sent to AssemblyAI for processing. The Windows edition has its own model catalog; use the Windows guide for that edition.
