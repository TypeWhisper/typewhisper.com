## About

Authenticated Provider CLIs make accounts already signed in to supported CLIs available as LLM providers in TypeWhisper. TypeWhisper starts the locally installed CLI for each request without importing or storing its login credentials.

The macOS and Windows editions are separate implementations with their own requirements and safeguards. Select your platform above for the exact setup steps and supported controls.

## What TypeWhisper sends

Only the workflow instruction and the transcript or selected input text are passed to the chosen CLI. TypeWhisper does not send audio, CLI credentials, unrelated app context, MCP tools, project rules, or previous CLI sessions.

The provider behind the CLI still processes the text through its cloud service. Its account plan, usage limits, and data-handling terms continue to apply.

OpenCode support exposes only Zen models whose complete current pricing metadata reports zero cost. Those offers can change or end at any time, and some free models may permit prompts and completions to be used for training. Review the selected model's [current Zen pricing and privacy terms](https://opencode.ai/docs/zen/) before sending personal or confidential text.

## Supported CLIs

| Provider        | macOS                                                                                  | Windows                                                                              |
| --------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Codex CLI       | Supported through `codex`                                                              | Supported through `codex.exe`                                                        |
| Claude Code CLI | Supported through `claude`                                                             | Supported through `claude.exe`                                                       |
| OpenCode Zen    | Current fully free models through `opencode`, including model-specific effort variants | Current fully free models through `opencode.exe`; no effort override in this edition |
| Antigravity CLI | Documentation-based best-effort processing through `agy`                               | Status preview through `agy.exe` only; no processing                                 |

## Core features

- Separate providers for the CLIs supported by the selected platform
- Automatic discovery of common native installation locations
- A manual executable picker when multiple installations exist or automatic detection is not suitable
- Version, login, and safety-control checks before a provider becomes available
- Manual status refresh and periodic background checks
- Temporary per-request working directories, timeouts, and strict input/output limits
- Structured text results without access to TypeWhisper audio or unrelated application data
- A dynamically refreshed OpenCode Zen catalog that exposes only text models whose complete reported pricing is zero
- On macOS, automatically refreshed Codex, OpenCode, and Antigravity models plus global and per-workflow effort selection
