## About

Gladia adds a dedicated cloud transcription engine to TypeWhisper. The macOS plugin introduced in PR #126 uses Gladia's Solaria API for live WebSocket streaming and falls back to upload plus polling when live transcription is unavailable.

## Features

- Real-time transcription via WebSocket streaming
- Automatic fallback to pre-recorded upload and polling
- Secure API key storage in the macOS Keychain
- Built-in API key validation in settings
- Language-aware transcription with broad multilingual support

## Transcription Models

| Model | ID |
| --- | --- |
| Solaria-1 | `solaria-1` |

## Configuration

- **API Key** - Create an API key in your Gladia account and paste it into the plugin settings.
- **Model** - Select `Solaria-1` in the plugin configuration dialog.

## Setup

1. Open TypeWhisper Settings > Integrations
2. Find Gladia under Transcription Engines and click Configure
3. Enter your Gladia API key and save it
4. Select Gladia as your transcription engine
