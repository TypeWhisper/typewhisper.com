## About

Live Transcript opens a translucent floating window that displays your transcription in real time while you record. The window stays above all other windows and across all spaces, so you can always see what is being transcribed. It works with any streaming transcription engine such as WhisperKit or Deepgram.

## Features

- Floating window opens automatically when recording starts
- Real-time streaming text as you speak
- Auto-paragraphing when you pause for more than 2 seconds
- Find text with Cmd+F
- Configurable font size (10-24pt)
- Window position and size remembered between sessions
- Auto-closes a few seconds after recording ends
- Stays above all windows and works across all spaces

## Configuration

- **Auto-open on recording** - When enabled, the transcript window opens automatically whenever you start recording. You can also open it manually from the menu.
- **Font size** - Adjust the text size from 10pt to 24pt using the slider.

## Setup

1. Open TypeWhisper Settings > Plugins
2. Find the Live Transcript plugin and click Configure
3. Optionally adjust auto-open behavior and font size
4. Start a recording - the transcript window will appear automatically
