## About

Deepgram provides fast, accurate cloud-based speech recognition using their Nova model family. The plugin uses WebSocket streaming for real-time transcription with smart formatting, automatic language detection, and support for 49+ languages.

## Features

- WebSocket streaming for real-time results
- Smart formatting (punctuation, capitalization, numerals)
- 49+ languages supported
- Automatic language detection
- Custom base URL support

## Transcription Models

| Model | ID |
| --- | --- |
| Nova 3 | `nova-3` |
| Nova 2 | `nova-2` |

On Mac, the language list follows the selected model: Nova 3 offers 59 languages, including Arabic and Kazakh, and Nova 2 offers 33. A profile or workflow that switches the model checks its language against that model. Without a selected language, the Mac add-on sends `language=multi` on streams and on REST requests, so Deepgram detects the language instead of assuming English.

Deepgram reads a stream at no more than 1.25 times real time. On Mac, audio longer than five minutes that is transcribed as a whole, such as a file, therefore goes straight to Deepgram's REST API. For recordings over 30 minutes, the request waits 2 seconds per audio minute for the answer, at most 10 minutes.

## Configuration

- **API Key** - Create an API key at console.deepgram.com.

## Setup

1. In TypeWhisper, open **Settings > Discover plugins** and install **Deepgram**. The add-on then appears in the Settings sidebar, and its page opens.
2. Enter your Deepgram API key.
3. Select Deepgram as your transcription engine in Settings or in a profile.
