## Über

Das Linear Plugin ermöglicht es dir, Issues in Linear direkt per Sprache zu erstellen. Kombiniere es mit einem benutzerdefinierten Prompt, der Titel und Beschreibung aus deiner Sprache extrahiert, und leite die LLM-Ausgabe als Action Plugin an Linear weiter. Das Plugin nutzt Linears GraphQL API, um Issues in deinem angegebenen Team mit korrekter Formatierung zu erstellen.

## Features

- Linear Issues per Sprache erstellen
- Automatische Titel-/Beschreibungsextraktion per LLM
- Konfigurierbares Team und Projekt
- Funktioniert mit jedem LLM-Anbieter
- GraphQL API Integration

## Konfiguration

- **API Key** - Erstelle einen persönlichen API-Schlüssel unter Linear Settings > API.
- **Team ID** - Die Linear Team-ID, unter der Issues erstellt werden.

## Einrichtung

1. Öffne TypeWhisper Einstellungen > Plugins
2. Finde das Linear Plugin und klicke auf Konfigurieren
3. Gib deinen Linear API-Schlüssel und die Team-ID ein
4. Erstelle einen benutzerdefinierten Prompt mit Linear als Ziel-Aktion
5. Diktiere und deine Sprache wird zu einem Linear Issue
