## Über diese Edition

Groq bietet Cloud-Transkription mit Whisper-Modellen und Textverarbeitung mit LLMs über einen API-Key. Du kannst Groq für Sprache, Workflow-Prompts oder beide Aufgaben auswählen. Verfügbare Modelle und Nutzungslimits hängen von deinem Groq-Konto ab.

## Features

- Cloud-Transkription mit Whisper-Modellen
- Mehrere Whisper-Modellvarianten
- LLM-Verarbeitung mit GPT-OSS-Modellen
- Kostenloses Kontingent mit großzügigen Rate-Limits
- OpenAI-kompatible API

## Transkriptionsmodelle

| Modell | ID |
| --- | --- |
| Whisper Large V3 | `whisper-large-v3` |
| Whisper Large V3 Turbo | `whisper-large-v3-turbo` |

## LLM-Modelle

| Modell | ID |
| --- | --- |
| GPT-OSS 20B | `openai/gpt-oss-20b` |
| GPT-OSS 120B | `openai/gpt-oss-120b` |

Aktualisiere den Modellkatalog in TypeWhisper, um die für dein Konto verfügbaren Modelle zu sehen. Prüfe [Groqs Abkündigungen](https://console.groq.com/docs/deprecations), wenn ein älteres gespeichertes Modell nicht mehr funktioniert.

Unter macOS ist ab Version 1.0.29 dieses Add-ons GPT-OSS 120B das Standard-LLM-Modell. Ein gespeichertes Modell, das in der aktuellen Modellliste fehlt, etwa das abgekündigte `llama-3.3-70b-versatile`, wird beim Senden einer Anfrage durch GPT-OSS 120B ersetzt. Deine Auswahl bleibt gespeichert und gilt wieder, wenn dein Konto das Modell erneut anbietet. Beim Start aktualisiert das Add-on eine zwischengespeicherte Modellliste, die einen Tag oder älter ist, im Hintergrund. Ein Workflow oder Fallback-Eintrag, der ein abgekündigtes Modell ausdrücklich nennt, behält es; wähle dort ein anderes Modell.

## Konfiguration

- **API-Schlüssel** - Registriere dich auf console.groq.com und erstelle einen kostenlosen API-Schlüssel.

## Einrichtung

1. Öffne in TypeWhisper **Einstellungen > Plugins entdecken** und installiere **Groq**. Das Add-on erscheint danach in der Seitenleiste der Einstellungen, und seine Seite öffnet sich.
2. Gib deinen Groq API-Schlüssel ein.
3. Wähle Groq als Transkriptions-Engine oder LLM-Anbieter.
