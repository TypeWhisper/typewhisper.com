## Über diese Edition

Groq bietet Cloud-Transkription mit Whisper-Modellen und Textverarbeitung mit LLMs über einen API-Key. Du kannst Groq für Sprache, Workflow-Prompts oder beide Aufgaben auswählen. Verfügbare Modelle und Nutzungslimits hängen von deinem Groq-Konto ab.

## Features

- Cloud-Transkription mit Whisper-Modellen
- Mehrere Whisper-Modellvarianten
- LLM-Verarbeitung mit GPT-OSS- und Qwen-Modellen
- Reasoning-Aufwand pro Modell auf dem Mac, zum Beispiel Niedrig für GPT-OSS 120B
- Kostenloses Kontingent mit großzügigen Rate-Limits
- OpenAI-kompatible API

## Transkriptionsmodelle

| Modell | ID |
| --- | --- |
| Whisper Large V3 | `whisper-large-v3` |
| Whisper Large V3 Turbo | `whisper-large-v3-turbo` |

## LLM-Modelle

| Modell | ID | Reasoning-Aufwand auf dem Mac |
| --- | --- | --- |
| GPT-OSS 20B | `openai/gpt-oss-20b` | Niedrig, Mittel (Groq-Standard), Hoch |
| GPT-OSS 120B | `openai/gpt-oss-120b` | Niedrig, Mittel (Groq-Standard), Hoch |
| Qwen 3.8 27B | `qwen/qwen3.8-27b` | Aus (Groq-Standard), Niedrig, Mittel, Hoch |
| Muse Spark | `meta-models/muse-spark-open` | Niedrig, Mittel, Hoch, Sehr hoch (Groq-Standard) |

Aktualisiere den Modellkatalog in TypeWhisper, um die für dein Konto verfügbaren Modelle zu sehen. Muse Spark erscheint erst, wenn du seine Nutzungsbedingungen in der Groq-Konsole akzeptiert hast.

Auf dem Mac legt die Einstellung „Reasoning-Aufwand“ fest, wie lange ein Modell nachdenkt, bevor es antwortet. Niedrigere Stufen antworten schneller und verbrauchen weniger Tokens, das passt gut zum Aufbereiten von Diktaten. Solange du keine Stufe wählst, nutzt Groq seinen eigenen Standard. Workflows können ihre eigene Stufe wählen. Prüfe [Groqs Abkündigungen](https://console.groq.com/docs/deprecations), wenn ein älteres gespeichertes Modell nicht mehr funktioniert.

## Konfiguration

- **API-Schlüssel** - Registriere dich auf console.groq.com und erstelle einen kostenlosen API-Schlüssel.

## Einrichtung

1. Öffne in TypeWhisper **Einstellungen > Plugins entdecken** und installiere **Groq**. Das Add-on erscheint danach in der Seitenleiste der Einstellungen, und seine Seite öffnet sich.
2. Gib deinen Groq API-Schlüssel ein.
3. Wähle Groq als Transkriptions-Engine oder LLM-Anbieter.
4. Wähle auf dem Mac einen Reasoning-Aufwand, wenn das LLM-Modell einen anbietet.
