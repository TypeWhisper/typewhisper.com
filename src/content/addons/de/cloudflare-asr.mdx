## Über

Cloudflare ASR ermöglicht es dir, Transkriptionsanfragen über einen Cloudflare Tunnel an ein beliebiges OpenAI-kompatibles Sprache-zu-Text-Backend weiterzuleiten. Das ist nützlich, wenn du einen Transkriptionsdienst selbst hosten möchtest, der hinter Cloudflares Netzwerk liegt, und dich über Service-Tokens statt API-Schlüssel authentifizieren willst.

## Features

- OpenAI-kompatibler API-Endpunkt für Transkription
- Cloudflare Tunnel-Unterstützung für sicheren Zugriff auf selbst gehostete Backends
- Service-Token-Authentifizierung (CF-Access-Client-Id / CF-Access-Client-Secret)
- Konfigurierbare Modellauswahl

## Konfiguration

- **Endpunkt-URL** - Die URL deines OpenAI-kompatiblen Transkriptions-Endpunkts hinter dem Cloudflare Tunnel.
- **CF-Access-Client-Id** - Deine Cloudflare Access Service-Token Client-ID.
- **CF-Access-Client-Secret** - Dein Cloudflare Access Service-Token Client-Secret.
- **Modell** - Das Transkriptionsmodell, das auf dem Backend verwendet werden soll.

## Einrichtung

1. Stelle einen OpenAI-kompatiblen Transkriptionsserver (z.B. faster-whisper-server) hinter einem Cloudflare Tunnel bereit
2. Erstelle einen Cloudflare Access Service-Token zur Authentifizierung
3. Öffne TypeWhisper Einstellungen > Plugins
4. Finde das Cloudflare ASR-Plugin und klicke auf Konfigurieren
5. Gib deine Endpunkt-URL und Service-Token-Zugangsdaten ein
6. Wähle Cloudflare ASR als Transkriptions-Engine in den Einstellungen oder in einem Profil
