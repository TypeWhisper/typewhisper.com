## Über

Das Webhook Plugin sendet jede Transkription als POST-Request an eine konfigurierbare URL. Nutze es, um TypeWhisper mit deinen eigenen Diensten, Zapier, Make, n8n oder jeder HTTP-kompatiblen Automatisierungsplattform zu verbinden. Die Payload enthält den transkribierten Text zusammen mit Kontext wie der Quell-App und URL.

## Features

- Transkriptionen per POST an beliebige URLs senden
- Enthält App-Kontext (Name, Bundle-ID, URL)
- Funktioniert mit Zapier, Make, n8n und eigenen APIs
- Pro Profil konfigurierbar
- JSON-Payload-Format

## Konfiguration

- **Webhook URL** - Der HTTP(S)-Endpunkt, der POST-Requests mit Transkriptionsdaten empfängt.

## Einrichtung

1. Öffne TypeWhisper Einstellungen > Plugins
2. Finde das Webhook Plugin und klicke auf Konfigurieren
3. Gib deine Webhook-URL ein
4. Transkriptionen werden nach jedem Diktat automatisch gesendet
