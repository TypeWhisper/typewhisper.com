## Über

Reson8 ergänzt TypeWhisper für macOS und Windows um Cloud-Sprache-zu-Text über die Reson8-API. Das Plugin kann Audio per WebSocket für Live-Transkription streamen und fällt auf den pre-recorded REST-Endpunkt zurück, wenn Streaming nicht verfügbar ist.

Das Plugin benötigt einen Reson8-API-Key. TypeWhisper validiert den Key in der Einstellungsoberfläche und speichert ihn über die sichere Plugin-Secret-Speicherung der App.

Quelle: [Reson8-Dokumentation](https://docs.reson8.dev/)

## Features

- Cloud-Transkription über Reson8 Speech-to-Text
- Echtzeit-WebSocket-Streaming mit REST-Fallback
- API-Key-Validierung in den Plugin-Einstellungen
- Sichere API-Key-Speicherung über TypeWhisper Plugin-Secrets
- Standardmodell von Reson8 plus eigene Modelle, die über die API geladen werden
- Eine einzelne Sprache aus der TypeWhisper-Sprachauswahl; bei mehreren ausgewählten Sprachen verwendet TypeWhisper die erste unterstützte Sprache, ohne Auswahl erkennt Reson8 automatisch
- Erweiterte Felder für eigene Basis-URLs und eigene Auth-Header
- Keine Übersetzungsunterstützung

## Transkription

| Modus | Verhalten |
| --- | --- |
| Live-Transkription | Streamt PCM-Audio per WebSocket an Reson8 und gibt Zwischentext aus, während Audio verarbeitet wird. |
| REST-Fallback | Sendet aufgezeichnetes Audio an den pre-recorded Reson8-Endpunkt, wenn Streaming fehlschlägt oder nicht genutzt wird. |
| Sprache | Gibt eine einzelne Sprache an Reson8 weiter. Bei mehreren ausgewählten TypeWhisper-Sprachen wird die erste unterstützte Sprache verwendet; ohne Sprachauswahl erkennt Reson8 automatisch. |

## Konfiguration

- **API-Key** - Füge einen Reson8-API-Key ein und warte, bis das Plugin **Gültiger API-Schlüssel** anzeigt.
- **Modell** - Nutze das Standard-Diktatmodell von Reson8 oder aktualisiere eigene Modelle, die für den API-Key verfügbar sind.
- **Eigene Basis-URL** - Überschreibt den Standard-Endpunkt `https://api.reson8.dev` für Gateways oder Proxies.
- **Eigener Auth-Header** - Überschreibt den Standard-Header `Authorization`, wenn ein Proxy einen anderen Headernamen erwartet.

## Einrichtung

1. Erstelle oder öffne ein Reson8-Konto.
2. Generiere einen API-Key.
3. Öffne TypeWhisper Einstellungen > Plugins.
4. Finde Reson8 und klicke auf Konfigurieren.
5. Füge den API-Key ein und warte auf die Validierung.
6. Aktualisiere optional eigene Modelle oder konfiguriere erweiterte Gateway-Einstellungen.
7. Wähle Reson8 als Transkriptions-Engine in den Einstellungen oder in einem Profil.
