## Über

File Memory bietet ein vollständig lokales und offline Gedächtnissystem für TypeWhisper. Transkriptionen und Kontext werden als JSON-Dateien auf der Festplatte gespeichert, und der Abruf erfolgt über eine einfache textbasierte Suche. Keine Cloud-Dienste oder API-Schlüssel nötig - alles bleibt auf deinem Mac.

## Features

- Vollständig offline - kein Netzwerkzugriff nötig
- JSON-Dateispeicher in einem lokalen Verzeichnis
- Textbasierte Suche für den Gedächtnisabruf
- Keine API-Schlüssel oder Cloud-Konten erforderlich
- Funktioniert ohne externe Abhängigkeiten

## Konfiguration

- **Speicherverzeichnis** - Der Ordner, in dem die Gedächtnisdateien gespeichert werden. Standardmäßig ein Verzeichnis innerhalb von TypeWhispers Application-Support-Ordner.

## Einrichtung

1. Öffne TypeWhisper Einstellungen > Plugins
2. Finde das File Memory Plugin und klicke auf Konfigurieren
3. Ändere optional das Speicherverzeichnis
4. Das Plugin speichert und ruft automatisch Erinnerungen ab, während du TypeWhisper verwendest
