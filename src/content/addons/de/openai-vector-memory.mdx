## Über

OpenAI Vector Memory bietet semantische Speicherung und Abfrage von Erinnerungen für TypeWhisper über die OpenAI Vector Store API. Im Gegensatz zum dateibasierten Memory-Plugin nutzt dieses Plugin Vektor-Embeddings für semantische Suche - es findet relevante Erinnerungen anhand der Bedeutung, nicht nur durch Schlüsselwort-Abgleich.

## Features

- Semantische Suche mit Vektor-Embeddings
- Cloud-basierter Speicher via OpenAI Vector Store API
- Findet kontextuell relevante Erinnerungen auch ohne exakte Schlüsselwort-Treffer
- Automatische Embedding-Generierung für gespeicherte Inhalte

## Konfiguration

- **API-Schlüssel** - Dein OpenAI API-Schlüssel mit Zugriff auf die Vector Store API.
- **Vector Store ID** - Die ID des zu verwendenden Vector Stores. Du kannst einen im OpenAI-Dashboard erstellen.

## Einrichtung

1. Erstelle einen OpenAI API-Schlüssel auf platform.openai.com
2. Erstelle einen Vector Store im OpenAI-Dashboard oder über die API
3. Öffne TypeWhisper Einstellungen > Plugins
4. Finde das OpenAI Vector Memory-Plugin und klicke auf Konfigurieren
5. Gib deinen API-Schlüssel und die Vector Store ID ein
6. Das Plugin speichert und ruft automatisch Erinnerungen ab, während du TypeWhisper nutzt
