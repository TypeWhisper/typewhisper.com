## Über

Qwen3 ASR ist TypeWhispers mitgelieferter lokaler Sprache-zu-Text-Anbieter für Qwen3-ASR auf Apple Silicon. Version `1.1.0` bringt die neue macOS-Konfiguration aus dem Screenshot: optionale HuggingFace-Token-Speicherung, Schnellauswahl für Modelle und zehn MLX-Modellvarianten vom kompakten quantisierten 0.6B-Download bis zum größeren 1.7B-BF16-Modell.

Die Transkription läuft lokal auf dem Gerät, nachdem das gewählte Modell heruntergeladen wurde. TypeWhisper sendet bei diesem Anbieter kein Audio an eine Cloud-Transkriptions-API, und für die Transkription ist kein API-Key erforderlich.

Die veröffentlichte Release ist die Quelle der Wahrheit für die öffentliche Version. Der Plugin-Release-Workflow kann das Bundle-Manifest während der Veröffentlichung patchen; ein lokaler Checkout oder Registry-Cache kann daher kurzzeitig noch eine ältere Version zeigen, während die Release fertigläuft.

Quellen: [Qwen3Plugin v1.1.0 Release](https://github.com/TypeWhisper/typewhisper-mac/releases/tag/plugin-qwen3-v1.1.0), [TypeWhisper Plugin-Registry](https://github.com/TypeWhisper/typewhisper-mac/blob/gh-pages/plugins-v1.json), [Qwen3 Plugin-Quellcode](https://github.com/TypeWhisper/typewhisper-mac/tree/main/TypeWhisperPluginSDK/Plugins/Qwen3Plugin)

## Voraussetzungen & Datenschutz

| Voraussetzung | Details | Warum es wichtig ist |
| --- | --- | --- |
| **Plattform** | macOS `14.0` oder neuer auf Apple Silicon (`arm64`). | Das macOS-Plugin nutzt Apples MLX-Stack und wird nur für Apple Silicon ausgeliefert. |
| **Download-Quelle** | Modelle werden von Hugging Face in TypeWhispers Plugin-Datenverzeichnis geladen. | Der erste Ladevorgang kann dauern und benötigt genug freien Speicherplatz für das gewählte Modell. |
| **Netzwerkzugriff** | Netzwerk wird für Modell-Downloads und optionale HuggingFace-Token-Prüfung genutzt. | Die Audio-Transkription selbst läuft lokal, sobald das Modell verfügbar ist. |
| **Zugangsdaten** | Kein API-Key nötig. Ein HuggingFace-Token ist optional. | Der Token hilft nur bei Hugging-Face-Download-Rate-Limits; er ist keine Transkriptionsauthentifizierung. |
| **Modellspeicher** | Die kleinsten 0.6B-Varianten zielen auf 8-GB-Macs. Das empfohlene 1.7B-6-bit-Modell zielt auf Macs mit 16 GB+. Die 1.7B-8-bit- und BF16-Optionen zielen auf Macs mit 32 GB+. | Wähle zuerst ein Modell, das zum RAM-Budget passt, bevor du auf maximale Qualität optimierst. |

## HuggingFace Token

Das HuggingFace-Token-Feld ist optional. TypeWhisper speichert einen bereinigten Token über den Plugin-Secret-Helper im macOS-Schlüsselbund und prüft ihn vor dem Speichern.

| Feld | Was es steuert | Beispiel |
| --- | --- | --- |
| **HuggingFace Token** | Ergänzt einen Token, den MLX/Hugging Face für Modell-Downloads nutzen kann. | Füge einen `hf_...`-Token ein, wenn du in Download-Rate-Limits läufst. |
| **Token anzeigen/verbergen** | Maskiert oder zeigt den Token beim Bearbeiten. | Nutze das Augen-Symbol, um einen eingefügten Token vor dem Speichern zu prüfen. |
| **Speichern** | Prüft den Token und speichert ihn nur, wenn Hugging Face ihn akzeptiert. | Warte auf **Gültiger HuggingFace-Token**, bevor du einen großen Modell-Download erneut startest. |
| **Entfernen** | Löscht den gespeicherten Token aus TypeWhisper. | Entferne ihn, wenn du das Hugging-Face-Konto wechselst oder den Mac weitergibst. |
| **Token wird geprüft...** | Zeigt, dass TypeWhisper den Token vor dem Speichern validiert. | Wenn die Prüfung hängen bleibt, prüfe den Netzwerkzugriff und versuche es erneut. |
| **Ungültiger HuggingFace-Token** | Der Token konnte nicht validiert werden. | Erstelle unter `huggingface.co/settings/tokens` einen neuen Token und speichere erneut. |

Der Token ist für normale Nutzung nicht erforderlich. Qwen3 ASR läuft weiterhin lokal und benötigt kein bezahltes Cloud-Sprache-zu-Text-Konto.

Quellen: [Hugging Face User Access Tokens](https://huggingface.co/docs/hub/security-tokens), [Qwen3 Plugin-Quellcode](https://github.com/TypeWhisper/typewhisper-mac/tree/main/TypeWhisperPluginSDK/Plugins/Qwen3Plugin)

## Transkriptionsverhalten

Qwen3 ASR erscheint in TypeWhisper als `Qwen3 ASR (MLX)`, nachdem ein Modell geladen wurde. Es unterstützt lokale Spracherkennung, aber keine Übersetzung.

| Einstellung oder Eingabe | Was TypeWhisper sendet | Hinweise |
| --- | --- | --- |
| **Profilsprache** | Einen Qwen-Sprachnamen, wenn die Profilsprache unterstützt wird. | `de` wird zu `German`; `fr` wird zu `French`. Leere oder nicht unterstützte Sprachen lassen Qwen3 im Auto-Detect-Modus. |
| **Auto-Detect** | Keinen erzwungenen Sprachhinweis. | TypeWhisper fällt nicht auf Englisch zurück, wenn im Profil keine unterstützte Qwen3-Sprache gesetzt ist. |
| **Wörterbuchbegriffe / Prompt-Kontext** | Eine Anti-Halluzinations-Anweisung plus normalisierte Fachbegriffe. | Begriffe wie `TypeWhisper` oder `MLX` werden, soweit vorhanden, als Kontext-Bias mitgegeben. |
| **Ins Englische übersetzen** | Nicht unterstützt. | Nutze einen anderen Transkriptionsanbieter, wenn der Workflow Übersetzung braucht. |
| **Lange oder geloopte Ausgabe** | TypeWhisper versucht wahrscheinlich geloopte Ausgabe erneut mit kürzeren Chunks und ohne Kontext-Bias. | Dieser Guard soll eine sauberere Transkription bevorzugen, wenn Qwen3 Wörter oder Phrasen wiederholt. |

Unterstützte Sprachcodes sind `zh`, `en`, `yue`, `ar`, `de`, `fr`, `es`, `pt`, `id`, `it`, `ko`, `ru`, `th`, `vi`, `ja`, `tr`, `hi`, `ms`, `nl`, `sv`, `da`, `fi`, `pl`, `cs`, `fil`, `tl`, `fa`, `el`, `ro`, `hu` und `mk`. `fil` und `tl` werden beide auf Filipino abgebildet.

Quellen: [Qwen3 Sprachbehandlung](https://github.com/TypeWhisper/typewhisper-mac/tree/main/TypeWhisperPluginSDK/Plugins/Qwen3Plugin), [TypeWhisper Plugin SDK Dictionary Terms](https://github.com/TypeWhisper/typewhisper-mac/tree/main/TypeWhisperPluginSDK)

## Einrichtungsbeispiele

### Schnelle lokale Transkription auf einem 8-GB-Mac

1. Öffne TypeWhisper Einstellungen > Plugins.
2. Konfiguriere **Qwen3 ASR**.
3. Lasse **HuggingFace Token** leer, außer Downloads laufen in Rate-Limits.
4. Klicke bei **Qwen3 0.6B (6-bit)** auf **Laden & Aktivieren**.
5. Wähle **Qwen3 ASR (MLX)** als Transkriptions-Engine in den Einstellungen oder in einem Profil.

### Empfohlene Einrichtung für die meisten Macs mit 16 GB+

1. Öffne TypeWhisper Einstellungen > Plugins.
2. Konfiguriere **Qwen3 ASR**.
3. Klicke bei **Qwen3 1.7B (6-bit)** auf **Laden & Aktivieren**.
4. Setze die Profilsprache, wenn du einen Sprachhinweis möchtest, oder lasse sie für Auto-Detect leer.
5. Ergänze Wörterbuchbegriffe für Produktnamen, Personen und Fachvokabular, die in der Transkription bevorzugt werden sollen.

### Höhere Qualität auf einem Mac mit 32 GB+

1. Öffne TypeWhisper Einstellungen > Plugins.
2. Konfiguriere **Qwen3 ASR**.
3. Klicke bei **Qwen3 1.7B (8-bit)** auf **Laden & Aktivieren**.
4. Nutze **Qwen3 1.7B (BF16)** nur, wenn du ausdrücklich ein unquantisiertes Validierungs- oder Vergleichsmodell willst.

### Modell wechseln oder entfernen

1. Öffne **Qwen3 ASR** in den Plugin-Einstellungen.
2. Klicke beim aktiven Modell auf **Deaktivieren**, wenn du dessen heruntergeladene Dateien entfernen willst.
3. Klicke beim nächsten Modell auf **Laden & Aktivieren**.
4. Öffne das Transkriptionsprofil erneut und bestätige, dass **Qwen3 ASR (MLX)** weiter ausgewählt ist.

## Hinweise

- Qwen3 ASR ist hier für die macOS-MLX-Implementierung dokumentiert.
- Ein HuggingFace-Token erhöht Download-Rate-Limits; er macht Qwen3 ASR nicht zu einem Cloud-Anbieter.
- Die Transkription läuft lokal, nachdem das gewählte Modell heruntergeladen wurde.
- Der Anbieter unterstützt Wörterbuchbegriffe und Prompt-Kontext mit einem Budget von `10.000` Zeichen.
- Übersetzung wird von diesem Anbieter nicht unterstützt.
- Die öffentliche `1.1.0`-Release benötigt TypeWhisper-Hostversion `1.2.1` oder neuer.
