## Über

Authentifizierte Provider-CLIs machen bereits in unterstützten CLIs angemeldete Konten als LLM-Anbieter in TypeWhisper verfügbar. TypeWhisper startet für jede Anfrage die lokal installierte CLI, ohne deren Anmeldedaten zu importieren oder zu speichern.

Die Editionen für macOS und Windows sind eigenständige Implementierungen mit eigenen Voraussetzungen und Schutzvorkehrungen. Wähle oben deine Plattform, um die passende Einrichtung und den genauen Funktionsumfang zu sehen.

## Was TypeWhisper übergibt

Nur die Workflow-Anweisung und das Transkript beziehungsweise der ausgewählte Eingabetext werden an die gewählte CLI übergeben. TypeWhisper sendet dabei weder Audio noch CLI-Anmeldedaten, weiteren App-Kontext, MCP-Tools, Projektregeln oder frühere CLI-Sitzungen.

Der Anbieter hinter der CLI verarbeitet den Text weiterhin über seinen Cloud-Dienst. Die Tarif-, Nutzungslimit- und Datenschutzregeln des jeweiligen Kontos gelten weiterhin.

Die OpenCode-Unterstützung zeigt nur Zen-Modelle an, deren vollständige gemeldete Preisangaben Kosten von null ausweisen. OpenCode kann diese Angaben aus seinem eigenen Cache liefern; zugleich können sich Angebote jederzeit ändern oder enden. Bei einigen kostenlosen Modellen dürfen Prompts und Antworten außerdem für das Training verwendet werden. Prüfe deshalb die [aktuellen Preis- und Datenschutzbedingungen von Zen](https://opencode.ai/docs/zen/) für das gewählte Modell, bevor du persönliche oder vertrauliche Texte sendest.

## Unterstützte CLIs

| Anbieter        | macOS                                                                                                        | Windows                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| Codex CLI       | Unterstützt über `codex`                                                                                     | Unterstützt über `codex.exe`                                                                                 |
| Claude Code CLI | Unterstützt über `claude`                                                                                    | Unterstützt über `claude.exe`                                                                                |
| OpenCode Zen    | Laut Katalog vollständig kostenlose Modelle über `opencode`, einschließlich modellspezifischer Effort-Stufen | Laut Katalog vollständig kostenlose Modelle über `opencode.exe`; diese Edition bietet keinen Effort-Override |
| Antigravity CLI | Dokumentationsbasierte Best-Effort-Verarbeitung über `agy`                                                   | Nur Statusvorschau über `agy.exe`; keine Verarbeitung                                                        |

## Zentrale Funktionen

- Separate Anbieter für die von der gewählten Plattform unterstützten CLIs
- Automatische Erkennung üblicher nativer Installationsorte
- Manuelle Auswahl der Programmdatei bei mehreren Installationen oder ungeeigneter automatischer Erkennung
- Prüfung von Version, Anmeldung und Sicherheitsfunktionen, bevor ein Anbieter verfügbar wird
- Manuelle Statusaktualisierung und regelmäßige Prüfungen im Hintergrund
- Temporäre Arbeitsverzeichnisse pro Anfrage, Zeitlimits und strenge Größenlimits für Ein- und Ausgabe
- Strukturierte Textergebnisse ohne Zugriff auf TypeWhisper-Audio oder weitere App-Daten
- Ein von der CLI gemeldeter OpenCode-Zen-Katalog, den TypeWhisper neu lädt und auf Textmodelle mit vollständig als null ausgewiesenen Kosten filtert
- Unter macOS automatisch neu geladene Codex-, OpenCode- und Antigravity-Modelle sowie globale und workflow-spezifische Effort-Auswahl
