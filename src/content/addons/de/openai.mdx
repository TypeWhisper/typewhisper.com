## Über

OpenAI / ChatGPT bringt hochwertige Sprache-zu-Text-Umwandlung über Whisper-Modelle und flexible Prompt-Verarbeitung über OpenAI- sowie ChatGPT-/Codex-Modelle in TypeWhisper. Das Plugin unterstützt sowohl klassisches Whisper als auch das neuere GPT-4o-Transcribe-Modell für bessere Genauigkeit. Unter macOS kannst du entweder einen normalen OpenAI-API-Key verbinden oder deinen bestehenden ChatGPT-Plus-/Pro- oder Codex-Login für die Prompt-Verarbeitung nutzen.

## Features

- Hochpräzise Whisper-Transkription
- GPT-4o Transcribe für verbesserte Genauigkeit
- GPT- und ChatGPT-/Codex-Modelle für LLM-Aufgaben
- o4-mini für schnelle, kosteneffiziente Verarbeitung
- Übersetzungsunterstützung über Whisper
- Browser-Login unter macOS
- Import eines bestehenden Codex-Logins unter macOS

## Konfiguration

- **API-Schlüssel** - Erstelle einen API-Schlüssel auf platform.openai.com. Er ist für Transkription erforderlich und kann auch für Prompt-Verarbeitung genutzt werden.
- **ChatGPT-Login** - Unter macOS kannst du dein bestehendes ChatGPT-Plus-/Pro-Abo oder deinen Codex-Login für Prompt-Verarbeitung nutzen, ohne dafür einen OpenAI-API-Schlüssel für Prompts zu hinterlegen.

## Einrichtung

1. Öffne TypeWhisper Einstellungen > Plugins
2. Finde das Plugin OpenAI / ChatGPT und klicke auf Konfigurieren
3. Wähle deine Verbindungsmethode:
4. Für API Key gibst du deinen OpenAI-API-Schlüssel ein
5. Für ChatGPT-Login unter macOS klickst du entweder auf Sign In In Browser oder auf Import Codex Login
6. Wenn du Transkription nutzen willst, hinterlege zusätzlich einen OpenAI-API-Schlüssel, auch wenn du ChatGPT-Login für Prompts verwendest
7. Wähle OpenAI / ChatGPT als Transkriptions-Engine oder LLM-Anbieter

## Hinweise

- Der ChatGPT-Login ist hier aktuell nur für macOS dokumentiert.
- Der ChatGPT-Login zeigt nur die unterstützten ChatGPT-/Codex-Modelle an.
- Browser-Login und Codex-Import sind für Prompt-Verarbeitung gedacht und ersetzen nicht den API-Schlüssel für Transkription.
